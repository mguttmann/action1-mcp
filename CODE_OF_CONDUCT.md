# Code of Conduct

This project adopts the
[Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/)
as its code of conduct. It applies to everyone who takes part in the
project's spaces: issues, pull requests, discussions and reviews.

In short: be respectful and constructive, assume good intent, and keep
the discussion about the work. Harassment, insults and personal attacks
are not tolerated.

## Reporting

Report unacceptable behavior confidentially, without a public issue or
comment:

- Open a private report through GitHub's private vulnerability
  reporting at
  <https://github.com/mguttmann/action1-mcp/security/advisories/new> and
  start the title with "Conduct:". Only the maintainer sees it. If that
  page is not available to you, use the contact options on the
  maintainer's GitHub profile,
  [@mguttmann](https://github.com/mguttmann), to ask for a private
  channel, without details.
- To report a single comment, issue or user to GitHub itself, use
  GitHub's "Report content" function on it.

Reports are handled confidentially: the reporter's identity and the
details are not shared without the reporter's consent.

The maintainer may remove, edit or reject comments, commits, code,
issues and other contributions that do not follow this code of conduct,
and may ban contributors who repeatedly or seriously break it, following
the enforcement guidelines of the Contributor Covenant.

Security vulnerabilities are not conduct issues: report them privately
as described in [`docs/SECURITY.md`](docs/SECURITY.md#reporting-a-vulnerability).
